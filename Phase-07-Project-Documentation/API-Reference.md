# PocketSmart AI – API Reference

Project: **PocketSmart AI – Your Smart Budget & Recommendation Assistant**

## Planner Routes

Home, Party and Jewelry planner routes connect user inputs to recommendation services.

## Authentication Routes

`/register`, `/login`, `/logout`, `/token`, `/session-info` and `/session-data` support authentication/session workflows.

## Recommendation/History

Recommendation detail and history routes support saved/reviewable plans.

## Important

Use the actual route definitions in `app/routes/` as the source of truth when preparing the final technical presentation.
