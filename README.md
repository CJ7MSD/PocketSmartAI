## Phase Structure

The repository is organized into the eight SmartBridge submission phases. Each phase contains a README and supporting files; Phase 05 also contains the working application source.

## Submission Checklist

- Public GitHub repository
- Phase-wise folders
- Working project source
- Test evidence
- Final documentation
- Public Google Drive demo video link

## Security

Do not commit `.env` or API keys. Use `.env.example` for configuration guidance.

## How to Run

Open Phase-05-Project-Development/PocketSmartAI, install requirements, configure `.env`, and run Uvicorn as described in SETUP.md.
