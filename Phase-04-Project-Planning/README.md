# Phase 04 – Project Planning

Project: **PocketSmart AI – Your Smart Budget & Recommendation Assistant**

## 1. Work Breakdown

Phase 1 ideation; Phase 2 requirements; Phase 3 design; Phase 4 planning; Phase 5 implementation; Phase 6 testing; Phase 7 documentation; Phase 8 demonstration.

## 2. Suggested Team Roles

Member 1: frontend/UI; Member 2: backend/API; Member 3: AI/live-data integration; Member 4: testing/documentation/demo. A 2–5 member team can redistribute these responsibilities.

## 3. Development Schedule

Week 1: ideation and requirements. Week 2: design and database/authentication. Week 3: planner modules and UI. Week 4: Gemini/live shopping integration. Week 5: testing and bug fixing. Week 6: documentation, GitHub organization and demonstration recording.

## 4. Deliverables

Working web application, source code, requirements file, phase-wise documents, test evidence, final documentation and demo video.

## 5. Risk Management

API quota/key failures → environment configuration and clear diagnostics. AI schema/model changes → validate against current API. Live product result changes → normalize provider responses and handle missing fields. Authentication/session bugs → dedicated auth tests. UI regressions → hard-refresh/cache-busting and cross-page testing.

## 6. GitHub Plan

Keep each phase in its own folder, commit work phase-wise, exclude secrets such as .env, and maintain a README with setup and run instructions.
